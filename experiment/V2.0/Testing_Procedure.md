# Testing Procedure

For each HTTP protocol (HTTP/1.1, HTTP/2, and HTTP/3), the following procedure was performed:

1. Start the required testing environment.

2. Open the target website using Microsoft Edge.

3. Connect to the browser through the Edge DevTools Protocol (CDP).

4. Request the target index.html document.

5. Record the required performance metrics.

6. Save the experimental result to the corresponding dataset.

7. Repeat the experiment 1000 times for each protocol.

8. Combine the three datasets into one master dataset.

9. Organise and analyse the collected data using Microsoft Excel.
