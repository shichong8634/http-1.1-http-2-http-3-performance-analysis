# Testing Procedure

For each protocol:

1. Open Google Chrome.

2. Open DevTools.

3. Enable Disable Cache.

4. Open Network panel.

5. Perform Hard Reload.

6. Record:
    - Requests
    - Transferred
    - TTFB
    - Resources
    - Finish
    - DOMContentLoaded
    - Load Time
   
7. Repeat 20 times.
